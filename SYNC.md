# Syncing with the upstream disposable-email-domains repository

This repo is a fork of [disposable/disposable-email-domains](https://github.com/disposable/disposable-email-domains)
that packages the domain list as a Ruby gem and extends it with additional domains
(`domains_ext.txt`) and a permanent blocklist of domains removed by the upstream
(`deleted_domains.txt`).

Work is done on the `upd` branch.

---

## Sync workflow

### 1. Merge from upstream

```bash
git fetch git@github.com:disposable/disposable-email-domains.git master
git merge FETCH_HEAD --no-edit
```

Resolve any merge conflicts (usually none — the domain list files are generated).

### 2. Collect deleted domains

Domains that the upstream removes (e.g. because their DNS expired) should
still be blocked by this gem. The rake task finds everything removed from
`domains.txt` since the last state of `master` and appends it to
`deleted_domains.txt`.

```bash
rake collect_deleted_domains
# or, if comparing against a specific ref:
BASE_REF=abc1234 rake collect_deleted_domains
```

Review the additions:

```bash
git diff deleted_domains.txt
```

If any domains in `deleted_domains.txt` should **not** be blocked (e.g. a
domain was removed upstream because it turned out to be a legitimate provider),
remove them manually before committing.

### 3. Commit and push

```bash
git add domains.txt domains_ext.txt deleted_domains.txt
# Include any other generated files that changed
git add domains*.txt domains*.json
git commit -m "Sync with upstream $(date +%Y-%m-%d)"
git push origin upd
```

### 4. Bump the gem version and release

Update the version in
[lib/disposable_email_domains/version.rb](lib/disposable_email_domains/version.rb)
(patch bump for routine syncs, minor bump for notable additions) and publish:

```bash
rake release
```

## File reference

| File | Purpose |
|------|---------|
| `domains.txt` | Main list, synced verbatim from upstream |
| `domains_ext.txt` | Domains added by this fork (not in upstream) |
| `deleted_domains.txt` | Domains removed upstream but permanently blocked here |
| `domains_sha1.txt` | SHA-1 hashes of all domains (generated by upstream) |
| `domains_mx.txt` | Domains with verified MX records (generated by upstream) |

---

## Inspecting what changed in a sync

```bash
# Net added domains
git diff master HEAD -- domains.txt | grep '^+[^+]' | sed 's/^+//'

# Net removed domains
git diff master HEAD -- domains.txt | grep '^-[^-]' | sed 's/^-//'

# Which commit removed a specific domain and why
git log --all -S 'example.com' --oneline -- domains.txt
git show <commit> -- domains_source_map.txt | grep 'example.com'
```
